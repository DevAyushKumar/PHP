Syntax of php:
-> When PHP parses a file, it looks for opening and closing tags.
<?php
Here you can write PHP code
>

<body>
<p>Some HTML text.</p>
<?php echo "This is text written in PHP"; ?>
</body>

-> Using semicolon to end a statement 
<?php
echo "This is text written in PHP";
?>

-> The closing tag implies a semicolon, and isn't needed for the last line in a block of php

<?php
echo "This is text written in PHP";
echo "This is text written in PHP"
?>

-> What about the files that only has php inside ?
<?php 
echo "This is text written in PHP";
//we don't include the closing tag "?>"

-> A advace example if embedding PHP
<body>
<?php
if(true){
    echo "<p>some HTML text</p>;
}
?>
</body>

<body>
<?php if (true) {?>
<p>Some HTML text.</p>
<?php}?>
</body>
